- 🤖 **AI-Powered Code Review** — Get instant feedback on your code with explanations

- 💡 **Real-Time Assistance** — Debug issues with AI guidance as you code

## 🎯 Getting Started

### Prerequisites
- Python 3.9 or higher
- Node.js 16+ (for frontend)
- Docker (optional, for containerized setup)

### Installation

```bash
# Clone the repository
git clone https://github.com/beltramofrancisco36-a11y/CodeMentor-AI.git
cd CodeMentor-AI

# Install backend dependencies
pip install -r requirements.txt

# Install frontend dependencies
cd frontend
npm install
cd ..

# Start the application
python app.py
```

Visit `http://localhost:5000` in your browser to get started!
